## 1. Favourite C# feature
My favourite feature is generic collections, especially List<T> and Dictionary<TKey, TValue>. They make it easier to store and retrieve data while keeping the code type-safe. In the graph exercises, dictionaries were particularly useful for storing edge weights and tracking distances.

## 2. Most disliked C# feature
The feature I found most challenging was nullable reference types. At first, it was easy to confuse a variable that could be null with one that should always contain an object. However, the warnings helped me think more carefully about missing data and the start node's parent.

## 3. Easiest practical or topic
Working with lists and dictionaries was the easiest topic for me once I understood their basic operations. Adding, finding and iterating through items gave clear results that were easy to check with small examples.

## 4. Most enjoyable practical or topic
The graph pathfinding exercises were the most enjoyable because the horse-and-bees example made the algorithms feel practical. Comparing BFS with Dijkstra showed why a route with fewer steps can still have a higher total cost.

## 5. One area to revise before the exam
I plan to revise graph traversal and algorithm complexity. I want to be able to trace BFS, DFS and Dijkstra by hand and explain when each algorithm is suitable, rather than only recognising the code.

## 6. Advice for new SDP students
Complete the weekly exercises regularly and test small changes as you go. When using AI, ask for explanations, run the code yourself and make sure you can explain the important steps without relying on the generated answer.

## 7. Suggestion for the course coordinator
More short worked examples showing the queue, stack or priority queue after each step would help students connect the code with the algorithm. A brief checklist of expected outputs and common mistakes for each practical would also be useful.
